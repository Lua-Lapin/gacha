# 役職の指定作成（手動入力）設計

## 背景と目的

現在、`people` に登録できるのはガチャを回した結果だけで、お題は各ガチャ定義
（`src/data/gachas.js` の `words.topics`）に含まれるものに限られる。

ガチャを引かずに、名前・形容詞・お題を直接入力して役職を作りたい。
入力するお題はガチャのお題リストに無いものでもよい。

## スコープ

- ガチャ画面に「役職を指定して作る」入力フォームを追加する
- 入力値から `title` を組み立て、既存の `POST /api/results` で `people` に保存する
- サーバー・DBスキーマは変更しない

スコープ外: 説明文（meaning / note / details）の入力、ガチャに紐づかない
（gachaId 無しの）役職作成、一覧画面からの導線。

## UI / 配置

新規コンポーネント `src/components/ManualTitleForm.jsx`（+ `ManualTitleForm.css` /
`ManualTitleForm.test.jsx`）を追加し、`App.jsx` のガチャビュー内、`GachaMachine` の
下にレンダリングする。

- 演出中・結果表示中（`phase !== 'idle'`）は非表示にする。ガチャ結果と入力欄が
  同時に並ばないようにするため。
- 閉じた状態では「役職を指定して作る」ボタンのみを表示する。押すとフォームが開く。
- フォームの入力欄は3つ:
  - **名前**
  - **形容詞**
  - **{itemLabel}** — 見出しはガチャ定義の `itemLabel` を使う（例: 「海の生き物」）
- 「作成」ボタンで保存する。成功したら「作成しました ✓」を表示し、入力欄をクリアして
  続けて作成できる状態に戻す。

`isExhausted`（お題を全部使い切った状態）でもこのフォームは使用できる。リスト外の
お題を入れられるのが主目的なので、ここではブロックしない。

## データフロー

責務を分ける。`ManualTitleForm` は入力と `title` の組み立てまでを持ち、保存そのものは
`App` が既存のガチャ保存と同じ経路で行う。

1. `ManualTitleForm` が `title = 形容詞 + お題`（`drawTitle` と同じ連結ルール）を作り、
   `onCreate({ name, adjective, topic, title })` を呼ぶ。`onCreate` は Promise を返す。
2. `App` が `color = pickCapsuleColor()`（ガチャと同じランダム配色）と
   `gachaId = 選択中のガチャ ID` を足し、
   `saveResult({ name, adjective, topic, title, color, gachaId })` → `POST /api/results`。

これにより `ManualTitleForm` は API もガチャ定義も知らずに済み、単体でテストできる。

保存に成功したら `App` の `usedTopics` にそのお題を追加する。ガチャの抽選除外
（同じお題を2人に出さない）は従来どおり維持し、手動入力だけがその制約の外に出る形にする。

### サーバー側の変更は不要

`POST /api/results` は必須フィールドの有無だけを見て、値の内容を検証せずに
`people` へ挿入する。画像生成のプロンプトは `gacha_id` のテンプレートに `title` を
差し込むだけなので（`server/prompt.js`）、お題がガチャのリストに無くても
カード生成はそのまま通る。DBスキーマの変更もない。

## バリデーション / エラー

- 3項目すべて必須。trim 後に空の項目があれば「作成」ボタンを無効化する。
- **重複チェックは行わない。** 既に使われているお題と同じ文字列でも作成できる。
- 保存 API が失敗した場合はエラーメッセージを表示し、入力値は保持する
  （`SaveResult` と同じ挙動）。
- エラー・完了メッセージは、いずれかの入力欄が変更された時点で消す。失敗後に
  入力を直している間、古いメッセージが残り続けないようにするため。

## テスト

`ManualTitleForm.test.jsx`（Testing Library）:

- 3項目を入力して「作成」を押すと、`onCreate` が
  `{ name, adjective, topic, title }` を正しく組み立てて呼ばれる
- いずれかの項目が空のときは「作成」ボタンが無効
- 既に使われているお題と同じ文字列でも作成でき、エラーにならない
- 成功時に入力欄がクリアされ、完了メッセージが表示される
- `onCreate` が reject したときにエラーメッセージが出て、入力値が残る

`App.test.jsx` に結合テストを1本追加:

- ガチャ画面でフォームを開き、入力して作成すると保存が呼ばれ、そのお題が
  以降のガチャ抽選から除外される
